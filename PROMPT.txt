研究磁流体发电的实验室要一个常驻核算服务，帮他们把法拉第式磁流体通道的电学性能算出来：导电流体在磁场中横穿通道时感应出多大开路电压，接上不同负载后能取出多大电流和功率，以及负载取到哪个值时提取功率最大。他们特别关心「扫一遍负载电阻、看功率曲线在哪个点见顶」这件事，所以服务不只是单点算一次，还要能对一段负载电阻区间做扫描、把功率随负载变化的曲线给出来，并标出峰值所在。服务只经 HTTP 提供接口，不带页面，也不做电站并网调度或值班台账，专注通道本身的感应与负载匹配。

物理内核是这样：开路感应电压等于磁感应强度、电极间距与流体速度三者相乘。通道自身有内阻，由电极间距、流体电导率和通道截面积决定。接上负载电阻后，回路电流等于开路电压除以内阻与负载之和，负载上提取的功率等于电流平方乘负载电阻。经典的最大功率传输发生在负载电阻等于内阻时，这就是扫描要找的峰值点。电导率趋于零时内阻趋于无穷、电流趋于零；不要把短路电流误当成开路电压，也不要用霍尔电压那套载流子迁移率乘磁场的公式来冒充这里的体感应电动势。

以下几条电学关系要作为正确性判据钉在自动化测试里：磁感应强度翻一倍，开路电压跟着翻一倍；单独把流体速度放大一倍，开路电压同样放大一倍；在内阻确定的情况下对负载电阻做扫描，功率曲线的峰值必须落在负载等于内阻处，把负载从等于内阻改到两倍内阻，提取功率应当下降；把电导率设为零时电流为零、功率为零；单点核算给出的某个负载下的功率，必须和扫描曲线在同一负载处取到的值一致，不能出现扫描用一套公式、单点用另一套的分叉。这些关系要能分别构造输入去检验。要预置一个数量级合理的通道算例（例如两特斯拉磁场配上百米每秒量级的流速）作可手算核对的基准，此时开路电压应落在百伏量级，钉进回归测试。

非法输入要在计算前挡住并说明原因：磁感应强度为负、电极间距不为正、流体速度为负、电导率为负、通道截面积不为正，都要用带原因的错误响应打回，不要让扫描跑到某个点才因为除零崩掉。扫描接口要允许调用方给定负载区间和采样密度，并对区间端点次序、采样点个数做合理性校验。进程里可以把常用的通道几何与工质参数命名成通道档反复调用，档在运行期间可靠存取即可、不必跨重启保留；两套通道档同时被扫描时，两条功率曲线各归各的，绝不能算串。

实现请分文件承载不同职责：开路电压与内阻的感应计算是一处，给定单个负载时的电流与功率求解是一处，对负载区间做扫描并定位功率峰值是一处，通道档的存取一处，输入合法性拦截一处；HTTP 那层只做请求收发和调度，感应公式与扫描循环这些计算内核不要往路由文件里堆。选 Python 3.12 配 Flask 实现，科学计算用标准库即可。仓库要支持用 Docker 一条命令构建并把服务容器启动、对外开放单点核算与扫描两个接口，随仓库带自动化测试，把磁场翻倍电压翻倍、峰值落在负载等于内阻处、单点与扫描在同一负载处一致这三条关系锁死。
